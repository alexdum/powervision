# PowerClimate Vision Explorer

Interactive spatial dashboard for exploring Copernicus PECD v4.2 climate-energy
boundaries across Europe. Built with R Shiny and MapLibre GL, developed as part
of Code for Earth 2026.

Browse different spatial tiers (countries, NUTS2 regions, ENTSO-E bidding zones,
study zones) on an interactive globe, click on regions to see metadata, switch
between basemaps, and explore climate-energy time-series data.

**Data sources**: Copernicus PECD v4.2, Eurostat GISCO NUTS 2021, ENTSO-E, EOX Sentinel-2.
